# Website fonts

The current site serves `Geist.woff2` locally, without a third-party font request.
Downloaded on 2026-10-02 from the [official Vercel Geist repository](https://github.com/vercel/geist-font),
`fonts/Geist/webfonts/Geist[wght].woff2`. Its SIL Open Font License is in
[Geist-OFL.txt](Geist-OFL.txt). Font weight range: 100–900.

The retained Space Grotesk and VT323 assets support earlier editable project artwork.
Their licenses are `OFL.txt` and `VT323-OFL.txt`.
